# Data

The dataset is the experimental vertical gas–liquid entrainment dataset from **Aliyu et al. (2017)** (1,367 measurements). It is third-party data and is not redistributed in this repository.



| Column | Meaning |
|---|---|
| `D` | Pipe diameter |
| `Usg` | Superficial gas velocity |
| `UsL` | Superficial liquid velocity |
| `rhol` | Liquid density |
| `rhog` | Gas density |
| `st` | Surface tension |
| `MuL` | Liquid viscosity |
| `Mug` | Gas viscosity |
| `e` | **Target:** entrained droplet fraction (0–1) |
